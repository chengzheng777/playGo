# src/AGENTS.md

本目录是浏览器端，只做展示和发送意图。

- 不要在客户端实现游戏规则、计分或胜负判断；这些以服务端 `viewFor` 为准。
- 通过 `store` 发消息，不要在组件里直接 `new WebSocket` 或拼协议。
- 共享类型从 `shared/protocol.ts` 引入，不要复制一份本地类型。
- 私密信息只使用服务端已裁剪的字段；不要从全量状态里“猜”别人的手牌/词。
- 新增视图优先复用现有组件和 CSS 变量；保持手机端和大屏端两套布局。
- 改 UI 行为时补/更新 `specs/` 验收项，必要时更新 `e2e/run.mjs`。
- 提交前跑 `pnpm verify`；改交互后尽量跑 `pnpm e2e`。
