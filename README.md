# playGo

局域网多人 Web 游戏平台：PC 起本地服务并创建房间，手机扫码即加入。

## 状态

**M2：大屏模式 + 头像**（2026-11-05）。
房主电脑当大屏播放词语，手机玩家分队答题、计分；回合制玩法用 WebSocket 足够。

## 快速开始

```bash
pnpm install
pnpm dev
```

浏览器打开 <http://localhost:8787>，这就是大厅：选一个游戏、输名字 → 创建房间 → 手机用系统相机扫二维码。
进入房间后房主还能换游戏、改规则；手机玩家点「加入游戏」，都加入后房主点「开始游戏」。

手机和电脑要在**同一个 WiFi**；Windows 首次运行时防火墙会弹窗，勾选「专用网络」。

## 玩法：一愚惊人

- **房主电脑是大屏 / 主持人**：显示当前词语、模式、倒计时和比分，不参加分队。
- **手机玩家**：自动分成青队 / 橙队，背对电脑屏幕答题。大厅里能看到房主选的游戏和当前规则，点「加入游戏」就算参赛。
- 每回合随机一种描述方式：**语言 / 动作 / 唇语 / 抢答**。
- 描述者站在电脑前看词，队友背对屏幕听描述；猜对后由**描述者或房主**点「猜对了」，该队 +1。
- **抢答**回合所有手机玩家都能输入答案，谁先答对，分算谁的队。
- 60 秒一回合，先到 **8 分**获胜；两者都能由房主在大厅调整（目标分 5/8/10/12，回合 30/45/60/90 秒）。
- 至少需要 2 名手机玩家（房主不参赛）。

### 头像

- 默认头像取名字首字，颜色由名字派生，同一个人每次进来一致。
- 点大厅右上角的头像可以换 emoji 和颜色，所有设备实时同步。

## 已验证的能力

- 创建房间，生成 4 位房间码与二维码（自动带局域网 IP）
- 大厅房间列表：所有房间实时可见，点一下就能加入；开局中的房间会标记并禁止加入
- 手机扫码加入、设置昵称与头像；房主与玩家角色分离
- 房间状态全量广播、准备状态同步、聊天
- 大厅规则设置：目标分与回合时长，房主改动实时同步；手机端能看到当前游戏与规则
- 断线后 90 秒内重连，座位与身份保留（进行中的游戏状态也会同步回来）
- 游戏大厅：4 个游戏位，1 个可玩、3 个占位
- 一愚惊人：大屏播放词语、手机分队、回合轮换、四种模式、倒计时、抢答、计分、胜负
- 词语只发给大屏；手机端在揭晓前拿不到词
- 关键节点动效：倒计时脉冲、答对彩带/闪光、结束庆祝，配合音效与震动

## 脚本

| 命令 | 说明 |
| --- | --- |
| `pnpm dev` | 开发模式，Vite 中间件 + HMR，默认 8787 |
| `pnpm build` | 构建前端到 `dist/` |
| `pnpm start` | 生产模式，需先 build；`PORT=xxxx` 可改端口 |
| `pnpm typecheck` | TypeScript 类型检查 |
| `pnpm engine` | 一愚惊人规则引擎的单元冒烟测试（不需要起服务） |
| `pnpm smoke` | 对着运行中的服务跑协议 + 游戏流程冒烟测试 |


## 手机连不上？

1. 确认手机连的是同一个 WiFi，不是 5G 蜂窝。
2. Windows 防火墙允许 Node 访问「专用网络」。
3. 路由器若开了「AP 隔离 / 访客网络」，设备之间互相不通，换手机热点。
4. 二维码下方可以切换网卡；虚拟网卡（VPN、Docker、WSL）通常连不通。
5. 端口 8787 被占用时会自动换成 8788…，以启动日志里的地址为准。
