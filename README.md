# playGo

局域网多人 Web 游戏平台：PC 起本地服务并创建房间，手机扫码即加入。

## 状态

## 核心结论

| 项 | 结论 |
| --- | --- |
| 通道 | WiFi 局域网 + WebSocket（`ws://`），延迟 1–10 ms |
| 蓝牙 | ❌ 纯浏览器不可行（无 BLE 外设广播 API，iOS 不支持） |
| 扫码 | 二维码内放 `http://<LAN-IP>:<port>/j/<code>`，用系统相机扫，无需 HTTPS |
| 本地服务 | Node.js 原生进程；浏览器只能当客户端 |
| 实时升级 | 需要更低延迟时再叠 WebRTC DataChannel，信令复用同一 WS |
