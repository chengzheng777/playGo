# playGo

[![CI](https://github.com/chengzheng777/playGo/actions/workflows/ci.yml/badge.svg)](https://github.com/chengzheng777/playGo/actions/workflows/ci.yml)

局域网多人 Web 游戏平台：PC 起本地服务并创建房间，手机扫码即加入。

## 状态

**M4：一愚惊人 + 一起 UNO + 拍颜色**（2026-11-05）。
房主电脑当大屏，手机玩家分队、出牌或拍照；回合制玩法用 WebSocket 足够。

## 快速开始

```bash
git clone https://github.com/chengzheng777/playGo.git
cd playGo
pnpm install
pnpm dev
```

浏览器打开 <http://localhost:8787>。第一次会先让你建一个用户（名字 + 头像），之后这台设备就记住了。
电脑端在大厅选游戏、开房；手机端大厅把房间列表放在最前面，底部有「创建房间」按钮，点开后再选游戏。

进入房间后房主还能换游戏、改规则；手机玩家点「加入游戏」，都加入后房主点「开始游戏」。

手机和电脑要在**同一个 WiFi**；Windows 首次运行时防火墙会弹窗，勾选「专用网络」。

## 玩法：一愚惊人

- **房主电脑是大屏 / 主持人**：显示当前词语、模式、倒计时和比分，不参加分队。
- **手机玩家**：自动分成青队 / 橙队，背对电脑屏幕答题。大厅里能看到房主选的游戏和当前规则，点「加入游戏」就算参赛。
- 每回合随机一种描述方式：**语言 / 动作 / 唇语 / 抢答**。
- 描述者站在电脑前看词，队友背对屏幕听描述；猜对后由**描述者或房主**点「猜对了」，该队 +1。
- **抢答**回合所有手机玩家都能输入答案，谁先答对，分算谁的队。
- 60 秒一回合，先到 **8 分**获胜；两者都能由房主在大厅调整（目标分 5/8/10/12，回合 30/45/60/90 秒）。
- 至少需要 2 名手机玩家（房主不参赛）。

### 一起 UNO

- 每人 7 张牌，按颜色 / 数字 / 功能牌出牌，先出完手牌获胜。
- 支持跳过、反转、+2、变色、+4；摸牌后可出则直接点牌，不出点「不出」。
- 大屏观战，玩家在手机上点牌出；房主不参赛。

### 拍颜色

- 每轮随机一个颜色（珊瑚橙、薄荷绿、天空蓝…），40 秒内用手机拍一张照片。
- 取照片**中心区域的平均色**，在 Lab 色彩空间里和目标色比距离，越接近排名越高。
- 得分 = **100 − 色差**（保留一位小数），满分 100；排名只决定展示顺序，不按名次发固定分。共 3 轮，总分最高获胜。
- 大屏展示所有照片（拍立得样式）、色差和得分；手机上只显示自己的结果。
- 拍照用的是系统相机 + 文件选择（`capture`），**不需要 HTTPS**，也不申请摄像头视频流，手机只做一次缩放取色，性能开销很小。

### 你画我猜

- 轮流由一名玩家在手机上画，**笔迹实时同步到 PC 大屏和所有手机**，猜的人在自己手机上也能看到。
- 其他人在手机上打字猜词；猜对的人 +10，画的人 +5。
- 每人画 1 轮，每轮 80 秒；大屏在作画阶段不显示词语。
- 画布归一化坐标、60ms 一批增量发送，单局笔迹点数有上限，避免拖慢手机。
- 平板（含 iPad）自动使用手机布局；画手本地用 coalesced 事件绘制，线条更连续。

### 头像

- 默认头像取名字首字，颜色由名字派生，同一个人每次进来一致。
- 点大厅右上角的头像可以换 emoji 和颜色，所有设备实时同步。

## 已验证的能力

- 创建房间，生成 4 位房间码与二维码（自动带局域网 IP）
- 首次打开创建本机用户（名字 + 头像），之后免填；大厅有用户栏可随时修改，房间内改会实时同步
- 大厅房间列表：实时刷新 + 手动刷新按钮，点一下就能加入；开局中的房间会标记并禁止加入
- 房间生命周期：没人（含房主）在线的房间立即从列表消失，30 秒后自动销毁
- 手机扫码加入、设置昵称与头像；房主与玩家角色分离
- 房间状态全量广播、准备状态同步、聊天
- 大厅规则设置：目标分与回合时长，房主改动实时同步；手机端能看到当前游戏与规则
- 断线后 90 秒内重连，座位与身份保留（进行中的游戏状态也会同步回来）
- 游戏大厅：一愚惊人、一起 UNO、拍颜色、你画我猜可玩，谁是卧底占位
- 一愚惊人：大屏播放词语、手机分队、回合轮换、四种模式、倒计时、抢答、计分、胜负
- 一起 UNO：发牌、出牌校验、跳过/反转/+2/变色/+4、摸牌与过牌、胜负
- 拍颜色：目标色、拍照取中心色、Lab 色差评分、拍立得展示、积分榜
- 你画我猜：轮流出题、笔迹实时同步大屏与手机、打字猜词、计分与轮次
- 词语只发给该看的人；UNO 手牌只发给本人；照片只在大屏揭晓时展示
- 关键节点动效：倒计时脉冲、答对彩带/闪光、结束庆祝，配合音效与震动

## 脚本

| 命令             | 说明                                       |
| ---------------- | ------------------------------------------ |
| `pnpm dev`       | 开发模式，Vite 中间件 + HMR，默认 8787     |
| `pnpm build`     | 构建前端到 `dist/`                         |
| `pnpm start`     | 生产模式，需先 build；`PORT=xxxx` 可改端口 |
| `pnpm typecheck` | TypeScript 类型检查                        |
| `pnpm lint`      | Biome 检查（格式 + 规则）                  |
| `pnpm test`      | Vitest 单元测试（三个游戏的规则引擎）      |
| `pnpm coverage`  | 覆盖率报告，输出到 `coverage/`             |
| `pnpm smoke`     | 对着运行中的服务跑协议 + 游戏流程冒烟      |
| `pnpm e2e`       | 真浏览器端到端（需先起服务、装 Chrome）    |
| `pnpm verify`    | typecheck + lint + test + build            |

```

  hub.ts           连接管理、消息分发、广播、游戏 tick

  qr.ts            二维码生成

  protocol.ts      协议类型与常量
  games.ts         游戏目录
  avatars.ts       默认头像与可选 emoji / 颜色

  lib/             震动、音效
docs/              设计与协议文档
scripts/           冒烟测试
```

## 手机连不上？

1. 确认手机连的是同一个 WiFi，不是 5G 蜂窝。
2. Windows 防火墙允许 Node 访问「专用网络」。
3. 路由器若开了「AP 隔离 / 访客网络」，设备之间互相不通，换手机热点。
4. 二维码下方可以切换网卡；虚拟网卡（VPN、Docker、WSL）通常连不通。
5. 端口 8787 被占用时会自动换成 8788…，以启动日志里的地址为准。
