# 005 · 你画我猜

- 状态：active
- 关联：`server/games/draw.ts`、`src/views/DrawView.tsx`
- 新增消息：`draw.delta`、`draw.clear`（只发给大屏）

## 背景

一名玩家在手机上画，笔迹实时同步到 PC 大屏和所有手机；其他人在手机上打字猜词。

## 行为

### 轮次与规则

- 参赛者轮流当画手，每人默认画 1 轮；房主可在开局前设置每人 1–3 轮、每轮 60–120 秒。
- 回合数 = 参赛人数 × 每人轮数；猜对或超时后进入揭晓（4.5 秒），再进入下一轮。
- 全部轮次结束按「总分 → 累计用时」定胜负。
- 结束后房主点「再来一局」可直接重开，不需要玩家重新准备。

### 词语可见性

- 画手的手机会显示词语。
- **大屏在作画阶段不显示词语**，否则猜的人直接看到了。
- 揭晓时所有人可见答案。

### 笔迹同步

- 手机画布坐标归一化到 0–1，随动作分批发送（约 60ms 一批）。
- 服务端只接受当前画手的笔迹，校验坐标、颜色、线宽、点数。
- 服务端把增量广播给房间内所有人（`draw.delta` / `draw.clear`），大屏和每个猜词手机都能实时看到。
- `room.state.draw.strokes` 也发给所有人，用于首次进入或重连时全量重绘。
- 单局笔迹总点数上限 6000，超出后丢弃后续笔画。
- 画手本地即时绘制，用 `getCoalescedEvents` 取中间点并保留上一个点，避免快速滑动时线条断续；清空时同时清本地画布。

### 计分

- 猜对：猜的人得 `10 + 速度加成`，速度加成为剩余秒数每 10 秒 +1（最多 +8）；画手 +5。
- 超时无人猜对：双方都不得分。
- 画手不能猜自己的词。
- 每次猜词（无论对错）都广播给所有人，显示成一条猜测记录。
- 累计用时：猜对者记「本轮已用时间」，其他人和超时记整轮时长；同分时累计用时少的获胜。

### 布局

- 游戏高度固定为 `100dvh`，画布按可用高度缩放，平板横屏不出现整页滚动。
- 平板 / iPad 使用手机布局。
- 猜词输入框聚焦时随键盘上移，避免被软键盘挡住。

## 接口

`game.action { stroke | clear | guess }`，`draw.delta` / `draw.clear` 见协议文档第 12 节。

## 验收标准

- [x] 只有画手能看到词，大屏与其他玩家看不到
- [x] 只有画手能提交笔迹，增量会累积到大屏
- [x] 清空只有画手生效
- [x] 猜对后加并进入揭晓
- [x] 超时进入揭晓，轮次走完会结束
- [x] 笔迹实时同步到所有手机与大屏（协议冒烟验证 `draw.delta`）
- [x] 房间内所有人都能看到每一次猜词
- [x] 同分时累计用时少的获胜
- [x] 结束后「再来一局」能直接重开

## 不做

- 撤销、橡皮擦、图层
- 猜词提示 / 字数提示
- 笔迹持久化
