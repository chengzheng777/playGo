# 005 · 你画我猜

- 状态：active
- 关联：`server/games/draw.ts`、`src/views/DrawView.tsx`
- 新增消息：`draw.delta`、`draw.clear`（广播给房间内所有人）

## 背景

一名玩家在手机上画，笔迹实时同步到 PC 大屏和所有手机；其他人在手机上打字猜词。
多人局里第一个猜对就结束会让后面的人来不及参与，因此一轮允许多人先后猜对，按顺序递减得分。

## 行为

### 轮次与规则

- 参赛者 = 开局时在房间内、**在线**且不是房主的手机玩家；离线玩家不进入本局，不占画手轮次。
- 参赛者轮流当画手，每人默认画 1 轮；房主可在开局前设置每人 1–3 轮、每轮 30–180 秒。
- 回合数 = 参赛人数 × 每人轮数；每轮除画手外的所有参赛者都是猜词者。
- 一轮在「所有猜词者都猜对」或「倒计时结束」时进入揭晓（4.5 秒），再进入下一轮。
- 首个猜对**不会**立即结束本轮，其他猜词者可以继续作答。
- 全部轮次结束按「总分 → 累计用时」定胜负。
- 结束后房主点「再来一局」可直接重开，不需要玩家重新准备。

### 词语可见性

- 画手的手机会显示词语。
- **大屏在作画阶段不显示词语**，否则猜的人直接看到了。
- 作画阶段其他猜词者看不到词语；揭晓时所有人可见答案。

### 自定义词库

- 房主可在大厅（`lobby` 阶段、选中「你画我猜」时）添加下一局使用的词语。
- 支持单个添加，也支持一次粘贴多个：用中文逗号、英文逗号、顿号、分号或换行分隔。
- 单个词 1–20 字；最多 200 个；同一词（忽略大小写与首尾空白）只保留一次。
- 自定义词**追加**到内置词库，抽取时和内置词混在同一个词池；不会替换内置词。
- 词库是房间规则，修改后下一局生效；所有房间成员都能看到已添加的词数与词列表。

### 笔迹同步

- 手机画布坐标归一化到 0–1，随动作分批发送（约 60ms 一批）。
- 服务端只接受当前画手的笔迹，校验坐标、颜色、线宽、点数。
- 服务端把增量广播给房间内所有人（`draw.delta` / `draw.clear`），大屏和每个猜词手机都能实时看到。
- `room.state.draw.strokes` 也发给所有人，用于首次进入或重连时全量重绘。
- 单局笔迹总点数上限 6000，超出后丢弃后续笔画。
- 画手本地即时绘制，用 `getCoalescedEvents` 取中间点并保留上一个点，避免快速滑动时线条断续；清空时同时清本地画布。

### 计分

- 同一轮允许多人猜对，按**猜对顺序**计分：
  - 第 1 位猜对：5 分；
  - 第 2 位猜对：3 分；
  - 第 3 位及以后猜对：1 分。
- 同一玩家在同一轮重复提交正确答案不重复得分。
- 画手：本轮每有 1 名猜词者猜对，画手 +1；如果本轮所有猜词者都猜对，画手本轮 0 分。
- 超时未猜对的玩家本轮不得分。
- 画手不能猜自己的词。
- 每次猜词（无论对错）都广播给所有人；猜对的那条记录带本轮得分。
- 累计用时：猜对者记「本轮从开始到答对的时间」；未猜对者与画手记整轮时长；同分时累计用时少的获胜。

### 布局与聊天

- 游戏高度固定为 `100dvh`，画布按可用高度缩放，平板横屏不出现整页滚动。
- 平板 / iPad 使用手机布局。
- 手机 320 / 360 / 390 宽度下，大厅、自定义词库、画布、猜词区和揭晓信息不出现横向滚动。
- 窄屏揭晓时「本轮画手」与「答案」分行展示，不出现单字换行。
- 猜词输入框聚焦时随键盘上移，避免被软键盘挡住。
- 对局中可通过侧边悬浮聊天栏收发公屏消息，规则见 `006-room-admin-and-chat.md`。

## 接口

`game.action { stroke | clear | guess }`，`draw.delta` / `draw.clear` 见协议文档第 12 节。
`game.settings { draw: { roundsPerPlayer, roundSeconds, customWords } }`，仅房主、仅大厅。

## 验收标准

- [x] 只有画手能看到词，大屏与其他玩家看不到
- [x] 只有画手能提交笔迹，增量会累积到大屏
- [x] 清空只有画手生效
- [x] 首位猜对后本轮继续，其他猜词者仍能作答
- [x] 按猜对顺序得 5 / 3 / 1 / 1 分，重复猜对不重复得分
- [x] 所有猜词者都猜对时立即揭晓，画手本轮 0 分
- [x] 超时才揭晓时，已猜对者保留得分，画手按猜对人数 +1
- [x] 超时进入揭晓，轮次走完会结束
- [x] 开局时离线玩家不进入本局、不占轮次
- [x] 房主添加的自定义词追加进词池，支持批量分隔与去重
- [x] 笔迹实时同步到所有手机与大屏（协议冒烟验证 `draw.delta`）
- [x] 房间内所有人都能看到每一次猜词与得分
- [x] 同分时累计用时少的获胜
- [x] 结束后「再来一局」能直接重开
- [x] 320 / 360 / 390 宽度下大厅、词库、画布与揭晓无横向溢出，窄屏揭晓头部正常分行

## 不做

- 撤销、橡皮擦、图层
- 猜词提示 / 字数提示
- 笔迹持久化
- 只有房主能用的「只抽自定义词」模式
- 游戏中踢人或加入
