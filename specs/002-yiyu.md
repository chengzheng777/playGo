# 002 · 一愚惊人

- 状态：active
- 关联：`server/games/yiyu.ts`、`src/views/GameView.tsx`

## 背景

房主电脑当大屏播放词语，手机玩家分队猜词；描述者看大屏比划，其他人背对屏幕。

## 行为

### 分队与回合

- 参赛者按进房顺序交替分入青队 / 橙队（座位 1、3、5… 青队；2、4、6… 橙队）。
- 回合在青 / 橙之间交替，青队先手。
- 每队内部按进队顺序轮流当描述者；掉线的人跳过。

### 模式

每回合随机一种，不连续重复同一种：

| 模式 | 约束                     |
| ---- | ------------------------ |
| 语言 | 不能说出词里的字         |
| 动作 | 只能比划，不能出声       |
| 唇语 | 只做口型                 |
| 抢答 | 全场都能在手机上输入答案 |

### 可见性

- 词语只发给大屏（房主）；手机玩家在揭晓前拿不到。
- 进入揭晓后所有人可见答案。

### 计分

- 普通回合：描述者或房主点「猜对了」，描述者所在队 +1。
- 抢答回合：参赛手机玩家输入答案，归一化后全等算对，先答对者所在队 +1；大屏和描述者不能抢答。
- 超时不加分；跳过不扣分。

### 计时与胜负

- 每回合 60 秒（房主可改 30/45/60/90）；揭晓约 2 秒后进入下一回合。
- 先到 8 分（可改 5/8/10/12）获胜。
- 描述者掉线不会卡住：到点自动结算，下回合跳过未连接的人。

## 接口

`game.settings`、`game.action { correct | skip | guess }`，见协议文档。

## 验收标准

- [x] 大屏能看到词，手机看不到
- [x] 描述者 / 房主可计分，其他玩家计分被忽略
- [x] 抢答仅参赛且非描述者有效，答对算其队伍
- [x] 超时自动进入揭晓并轮到下一队
- [x] 达到目标分结束并产生胜者
- [x] 掉线状态同步到视图，且不阻塞回合
