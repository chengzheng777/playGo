# 007 · 房主参赛与独立大屏

- 状态：active
- 关联：`shared/protocol.ts`、`server/rooms.ts`、`server/hub.ts`、`src/store.ts`、`src/views/LobbyView.tsx`、四款游戏视图
- 新增消息：`room.hostplays`
- 新增路由：`/s/:code`（观战大屏）

## 背景

现在房主一定是大屏，不能参赛；大屏是跑游戏的必需项。很多场景只有几台手机、没有电视/电脑，
或者房主本人也想一起玩。需要让房主选择「只做大屏」还是「我也参赛」，参赛时另开一个大屏观战链接。

## 行为

### 房主模式

- 仅大厅阶段、仅房主可切换，默认「只做大屏」，保持现有行为。
- **只做大屏**：房主角色为 `screen`，不进入参赛名单，不需要准备；房主页面就是大屏。
- **我也参赛**：房主角色变为 `player`，自动准备；房主页面变成玩家视角；房主仍是房主，保留开始、改规则、踢人、结束本局等控制。
- 房主参赛后，开局条件按「参赛者」计算：至少 2 名在线参赛者（含房主），且都已准备；不再要求「2 名手机玩家」。
- 切回「只做大屏」后房主退出参赛名单，不再占轮次、不再需要准备。
- 模式只在 `lobby` 阶段可改，游戏进行中不可切换。

### 独立大屏

- 房主参赛时，大厅显示独立大屏链接 `/s/:code`；大屏是可选的，不打开也能正常开局。
- 打开链接的页面以 `spectator` 身份加入，显示为「大屏」，不需要本机用户资料，使用独立 token；刷新后按 token 重连。
- 大屏可以在 `lobby`、`playing`、`ended` 任意阶段加入；不占 8 名玩家的容量，不进入参赛名单，不需要准备，不能出牌/猜词/拍照/画画。
- 大屏只做展示，不显示房主控制按钮；房主可在玩家列表把大屏移出。
- 房主参赛时房主自己的页面是玩家，不是大屏；大屏必须通过独立链接打开。
- 大屏断线后保留身份 90 秒，可重连；离线大屏不计入人数。

### 各游戏可见性

- **一愚惊人**：参赛者包含房主（如果参赛）。词语发给大屏和当前描述者的手机；房主参赛但不是描述者时看不到词。
  只有描述者、或「未参赛的房主大屏」能点「猜对了 / 跳过」；独立大屏是观战席，不能计分。
- **一起 UNO**：房主参赛时正常发牌、出牌；大屏没有手牌、不能出牌，只显示牌桌与张数。
- **拍颜色**：房主参赛时正常拍照、计分；揭晓照片只发给大屏（独立大屏或未参赛的房主大屏），参赛房主看不到别人的照片。
- **你画我猜**：房主参赛时可当画手或猜词者；大屏在任何阶段都看不到词，只显示画布与比分。

### 房间列表与人数

- 大厅房间列表的「人数」只统计参赛者，不把大屏算进去。
- 容量上限只限制参赛者；观战大屏可以额外加入。

## 接口

```jsonc
// C→S，仅房主、仅 lobby
{ "v": 1, "type": "room.hostplays", "data": { "enabled": true } }
```

- 成功：更新 `room.hostPlays`、房主 `role` 与 `ready`，广播 `room.state`。
- 非房主 / 非 `lobby`：回 `NOT_HOST` / `BAD_PHASE`。
- 观战大屏仍用 `room.join { code, role: "spectator" }`，不需要新消息；`room.join` 对 spectator 放开阶段限制与重名限制，且不计入容量。
- `room.state.room.hostPlays` 同步给所有人；`you.role` 为 `screen` / `player` / `spectator`。

## 验收标准

- [x] 房主只在大厅能切换「只做大屏 / 我也参赛」
- [x] 房主参赛时自动准备，角色变为 player，所有端同步
- [x] 房主 + 1 名玩家可以开局；房主单独不能开局
- [x] 房主参赛时出现独立大屏链接，大屏可选、不开也能玩
- [x] `/s/:code` 以 spectator 加入，大厅和游戏中都能进入，刷新可重连
- [x] 大屏不占容量、不需要准备、不能执行任何游戏动作，也没有房主控制
- [x] 房主可在玩家列表移出大屏
- [x] 一愚惊人：描述者手机和大屏能看到词；参赛房主非描述者看不到词，也不能计分
- [x] UNO：参赛房主有手牌；大屏无手牌、不能出牌
- [x] 拍颜色：大屏能看到照片；参赛房主看不到别人的照片
- [x] 你画我猜：大屏在作画阶段拿不到词；参赛房主按正常玩家规则参与
- [x] 房间列表人数不包含大屏
- [x] 320/360/390 移动端下房主模式开关和大屏链接不横向溢出

## 不做

- 多个控制端 / 转移房主控制
- 大屏的私聊、弹幕、投票
- 观战大屏的鉴权密码
- 游戏中切换房主是否参赛
