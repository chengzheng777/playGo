# 004 · 拍颜色

- 状态：active
- 关联：`server/games/color.ts`、`src/views/ColorView.tsx`、`src/lib/photo.ts`

## 背景

每轮给一个颜色，玩家用手机拍一张照片，画面中心越接近目标色得分越高。

## 行为

### 轮次

- 共 3 轮，每轮 40 秒；全部在线玩家提交会提前揭晓。
- 目标色从固定色板随机抽取（珊瑚橙、薄荷绿、天空蓝…），一轮内不重复。
- 揭晓 9 秒后进入下一轮；3 轮结束按总分定胜负。

### 拍照

- 使用 `<input type="file" accept="image/*" capture="environment">` 调起系统相机。
  **不使用 `getUserMedia`**：局域网 HTTP 不是安全上下文，且实时预览开销大。
- 客户端把图压到最长边 360px、JPEG 0.62，取中心 44% 区域的平均 RGB，和图片一起上传。
- 单帧上限 512 KB；照片 `data:image/` 且不超过 320 KB 字符。

### 计分

- 服务端把 RGB 转到 Lab，用 CIE76 色差 ΔE 比较。
- 单轮得分 `max(0, 100 − ΔE)`，保留一位小数；排名只影响展示顺序，不发固定名次分。
- 色差 ≥ 100 记 0 分。

### 可见性

- 照片只在大屏（房主）的揭晓视图里下发；手机端只看到自己的 RGB、色差和分数。
- 未提交的玩家本轮 0 分，不参与排名。

## 接口

`game.action { shoot }`，见协议文档。

## 验收标准

- [x] 开局给出目标色，3 轮
- [x] 全部提交提前揭晓
- [x] 完全命中目标色得 100 分
- [x] 大屏能看到照片，玩家看不到别人的照片
- [x] 3 轮结束产生胜者
- [x] 手机端不申请摄像头流，只处理一次缩放与取色

## 不做

- 多人同时多张、连拍
- 照片持久化存储
- 目标色由玩家自定

## 测试映射

| 验收项                                       | 覆盖方式                                 |
| -------------------------------------------- | ---------------------------------------- |
| 目标色、提前揭晓、Lab 排序、照片可见性、结束 | `pnpm engine`                            |
