# 003 · 一起 UNO

- 状态：active
- 关联：`server/games/uno.ts`、`src/views/UnoView.tsx`

## 背景

大屏观战，手机玩家各自看手牌出牌。基础 UNO 规则，先出完手牌获胜。

## 行为

### 牌与发牌

- 108 张：四色各 0×1、1–9×2、跳过×2、反转×2、+2×2；wild×4、wild+4×4。
- 每人 7 张，剩余作牌堆；翻开第一张数字牌作为弃牌堆顶。

### 出牌

- 可出：颜色与当前色相同，或数字/功能与弃牌堆顶相同，或 wild / wild+4。
- wild 与 wild+4 必须选择颜色。
- 大屏（房主）不参赛、无手牌、不能出牌。

### 功能牌

| 牌     | 效果                     |
| ------ | ------------------------ |
| 跳过   | 下一位跳过               |
| 反转   | 方向翻转；两人局视作跳过 |
| +2     | 下一位摸 2 张并跳过      |
| wild+4 | 下一位摸 4 张并跳过      |

### 摸牌与过牌

- 摸一张：摸到可出的牌则进入「可出 / 不出」，只能出刚摸到的那张；否则自动轮到下一位。
- `pass` 只在摸牌后有效。

### 可见性

- 手牌只发给本人；其他人只看到张数。
- `playableIds` 只在本人回合（且未处于摸牌选择）时计算。

## 接口

`game.action { play | draw | pass }`，见协议文档。

## 验收标准

- [x] 每人 7 张，大屏无手牌，手机有手牌
- [x] 非当前玩家不能出牌
- [x] 出牌后手牌减少
- [x] 摸牌生效（手牌 +1 或轮转）
- [x] 能一路打到有人出完并产生胜者

## 不做

- 「UNO！」喊话与罚牌
- +2 / +4 叠加
- 计分制（多局累计）
